# Push-in lento

## O que é
Dentro de cada trecho, a câmera se aproxima devagar (+4 %).

## Quando usar
Fala mais longa, para o quadro não ficar parado.

## Quando não usar
Junto de câmera tremida ou de tracking forte.

## Contenção
Não conta como acento.
